# More Upgraded Card Previews
A QoL mod for Slay the Spire 2 that adds optional upgrade previews to card rewards, card selection screens, and combat card piles.

## Features
Upgrade previews are available on the following screens:

### In-combat
Card piles:
* Draw Pile
* Discard Pile
* Exhaust Pile

Card generators:
* Cards
* Potions
* Relics

### Post-combat
Card Rewards

### Selection screens
#### Vanilla
These screens already have an upgrade preview option in the base game:
* Card Upgrade
* Card Transform

#### Added
* Card Removal
* Card Duplicate
* Card Enchant


## Requirements

* Slay the Spire 2 minimum version 0.107.1
* STS2-RitsuLib 0.6.2


## Installation
### Steam Workshop

Subscribe to the mod through the [Slay the Spire 2 Workshop.](LINKKKKKKKKKKKKKKKKKKKKKKKK)

### Manual installation
Install [STS2-RitsuLib](https://github.com/BAKAOLC/STS2-RitsuLib/releases/) first.

Download the [latest release](https://github.com/3m-code/MoreUpgradedCardPreviews/releases) and extract the mod into the game's `mods` directory.

The default Steam installation path is usually: `C:\SteamLibrary\steamapps\common\Slay the Spire 2\mods`


The mod folder should contain:
```text
MoreUpgradedCardPreviews/
├── mod_manifest.json
├── MoreUpgradedCardPreviews.dll
└── MoreUpgradedCardPreviews.pck
```

The exact folder and file names must match the release package.


## Compatibility

The mod is client-side and works in unmodded multiplayer.

The mod is compatible with both the main and beta branches of Slay the Spire 2.
